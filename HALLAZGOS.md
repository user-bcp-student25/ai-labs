# HALLAZGOS

## Mapa y contrato observado (web)

- `web/src/main.ts` arranca la aplicacion standalone; `web/src/app/app.component.ts` aloja el router outlet y `web/src/app/app.routes.ts` carga login y dashboard. La raiz y las rutas desconocidas redirigen a `/login`.
- Login y dashboard conservan la presentacion/navegacion; `AuthService` centraliza login y sesion, y `TasksService` consulta tareas. Axios continua como transporte; las URLs estan en configuracion de entorno.
- `web/package.json` declara Angular `21.2.19` y Axios `1.20.0`; Lodash fue retirado. La auditoria posterior ya no lista advisories para Axios/Lodash, aunque siguen advisories transitivos detallados en `PLAN.md`.
- Flujo observado y preservado: el formulario envia `username`, `password` y `client` a `POST http://localhost:8080/auth/login`. Con token y usuario, `AuthService` guarda token, usuario y preferencias en `localStorage`, y login navega a `/dashboard`. `TasksService` solicita `GET http://localhost:8000/api/tasks?owner=<username>` con `Authorization: Bearer <token>`; dashboard excluye `ARCHIVED` y muestra las restantes. Sin token redirige a `/login`. Logout borra token/usuario, conserva preferencias y vuelve a `/login`; no se agrega llamada HTTP de logout. H-WEB-01 sigue pendiente porque `localStorage` es accesible a JavaScript.
- `docs/ENDPOINTS.md` documenta el contrato observado unicamente en web y las preguntas abiertas; no es un contrato acordado con los servicios. La caracterizacion local paso; no se contactaron servicios externos.
